| **[rajagurunath / Active-Learning-in-Text-classification](https://github.com/rajagurunath/Active-Learning-in-Text-classification)** | Минималистичный учебный проект интерактивной разметки текстов с самописным классификатором KNN и косинусным сходством. | • Провести **рефакторинг кода**: заменить медленный линейный поиск ближайших соседей на векторные операции или KD-дерево.<br>• Добавить сохранение истории наград и автоматическое дообучение весов при исправлении метки пользователем. |
