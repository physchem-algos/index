| Репозиторий | Краткое описание | Что можно дописать или переписать (задачи для студентов) |
| :--- | :--- | :--- |
| **[modAL-python / modAL](https://github.com/modAL-python/modAL)** | Легковесный модульный фреймворк для Active Learning поверх `scikit-learn` (работает на CPU за секунды, без тяжелых нейросетей). | • Реализовать собственную **стратегию выбора текстов (Query Strategy)** на базе $\varepsilon$-жадного бандита (Epsilon-Greedy) или UCB вместо стандартного `uncertainty_sampling`.<br>• Написать симулятор разметчика (оракула), который возвращает метку класса с заданной вероятностью ошибки, и замерить скорость сходимости. |
| **[karpathy / minbpe](https://github.com/karpathy/minbpe)** | Эталонная минималистичная реализация токенизатора **Byte Pair Encoding (BPE)** от Андрея Карпатого на чистом Python (всего пара файлов по ~100 строк). | • Оптимизировать цикл обучения (`train`), где на каждом шаге заново пересчитываются частоты пар символов: применить **кучу (heapq)** или кэширование для ускорения.<br>• Обучить свой токенизатор на корпусе биологических терминов / последовательностей ДНК (актуально для ФБМФ) и сравнить коэффициент сжатия со стандартным словарем. |

| **[bserna-usgs / text-annotator](https://github.com/bserna-usgs/text-annotator)** | Очень простое однофайловое веб-приложение на **Flask** для разметки и верификации текстовых фрагментов человеком (Human-in-the-loop). | • Осовременить код под Python 3 и добавить **очередь приоритетов (heapq)**, чтобы приложение в первую очередь показывало разметчику самые «спорные» тексты (Active Learning).<br>• Добавить экспорт размеченных данных в формат JSONL для дообучения моделей. |
